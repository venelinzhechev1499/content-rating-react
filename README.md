# content-rating-react
React component that allows users to like or dislike content, displaying individual counts and the total number of ratings using React state and event handling.

This project is a simple React component that demonstrates state management and event handling.

Users can:
- Like or dislike a piece of content
- See separate counters for likes and dislikes
- View the total number of ratings updated in real time

The component is built using a class-based React approach and is suitable for practicing React fundamentals such as `state`, `setState`, and event handling.

Technologies
- React
- JavaScript (ES6)
- CSS

Purpose
This project was created as part of a practice exercise to reinforce React state management and UI interaction concepts.
